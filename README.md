# 🎮 Rock Paper Scissors

A simple Rock Paper Scissors game built using Python. The player competes against the computer, which randomly selects Rock, Paper, or Scissors.

## 🚀 Features

- User input to select Rock, Paper, or Scissors.
- Random selection by the computer.
- Determines the winner using conditional statements.
- Handles invalid user input.
- Displays both the player's and computer's choices.

## 🛠️ Technologies Used

- Python
- `random` module
- Dictionaries
- Conditional statements
- User input and output

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python 1_Rock_Paper_Sissore.py
```
